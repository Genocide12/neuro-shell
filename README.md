# NeuroShell

**Красивая графическая оболочка для вашего API-ключа.** Один HTML-файл — и полноценный интерфейс чата со стримингом, как у «больших» сервисов, только с вашим ключом и вашими правилами.

Вставьте ключ — и работайте. Никакой телеметрии, никакой отправки данных на сторонние серверы (кроме вашего API), всё хранится локально в браузере.

![NeuroShell](https://img.shields.io/badge/версия-1.1.0-6c8cff) ![тип](https://img.shields.io/badge/тип-один__HTML__файл-green) ![зависимости](https://img.shields.io/badge/зависимости-0-blue)

## Что умеет

- **Чат со стримингом** — ответ появляется по мере генерации, как в ChatGPT
- **Цены на токены** — тарифы всех моделей (вход/выход за 1M): встроенные цены Anthropic, цены от сервера и свои; под каждым ответом — фактический расход и стоимость, у поля ввода — оценка промпта в долларах
- **Работает с любым OpenAI-совместимым API** — ваш прокси, OpenRouter, OpenAI, локальная ollama…
- **В отдельном окне** — десктопная версия открывается как самостоятельное приложение, без вкладок и адресной строки браузера
- **Встроенные инструкции («характер»)** — 4 пресета на выбор, поле системного промпта редактируется
- **Артефакты** — попросите модель сделать HTML-страницу, и она откроется в живом предпросмотре рядом с чатом
- **Вложения** — текстовые файлы и картинки (drag&drop, вставка из буфера)
- **История чатов** — поиск, переименование, хранение в localStorage
- **Тёмная тема**, адаптивная вёрстка (телефон/планшет/десктоп)
- **Экспорт/импорт** бэкапа настроек и чатов в один JSON-файл
- **Ноль зависимостей** — ни CDN, ни библиотек, работает даже офлайн

## Быстрый старт

### Веб-версия (без установки)

Откройте **[страницу приложения](https://genocide12.github.io/neuro-shell/)** →

1. Нажмите «Настройки» (внизу слева)
2. Вставьте **API-ключ**
3. Base URL и модель подставятся автоматически (`https://api.gym-rat.online/v1`, `claude-opus-5-5`) — можно поменять на любой другой сервис
4. Нажмите «Проверить» — убедитесь, что соединение работает (если выпала ошибка `Failed to fetch` — см. раздел [«Если "Проверка не удалась" (CORS)»](#если-проверка-не-удалась-failed-to-fetch-cors))
5. «Готово» — пишите!

> Ключ хранится только в localStorage вашего браузера и уходит напрямую в API. Данные не проходят через какие-либо серверы NeuroShell — их и нет.

### Десктопная версия (Windows)

Скачайте `NeuroShell.exe` со [страницы релизов](https://github.com/Genocide12/neuro-shell/releases) → запустите — откроется **отдельное окно приложения** (без вкладок, адресной строки и панелей браузера — режим `--app` в Edge/Chrome; если ни один из них не найден, откроется браузер по умолчанию).

Отличия от веб-версии:

- **своё окно**, как у обычной программы; закройте окно — приложение завершится само
- работает с **любыми** API, даже без CORS (запросы идут через встроенный локальный прокси)
- **настройки и история сохраняются** между запусками: адрес приложения фиксирован (`127.0.0.1:8947`), поэтому браузерный профиль не теряется (в v1.0 порт был случайным и всё сбрасывалось)
- повторный запуск не плодит копии: просто откроется окно уже работающей
- чёрное консольное окно не показывается вовсе

> Порт можно поменять переменной окружения `NS_PORT`. SmartScreen может предупредить о неизвестном издателе — это нормально для exe без цифровой подписи. Нажмите «Подробнее → Выполнить в любом случае».

## Цены на токены

Нажмите на бейдж модели вверху (или кнопку $ в настройках) — откроется таблица тарифов всех моделей: вход/выход за 1M токенов, источник и поиск.

- **Встроенные** — официальные цены Anthropic (ноябрь 2026): Opus 5.5 — $4/$20, Sonnet 5.5 — $2/$10, Haiku 5.5 — $0.10/$0.50, Fable — $10/$50, и т.д. для всех поколений; для сторонних моделей (GPT, DeepSeek, Qwen) — приближения
- **С сервера** — если ваш API отдаёт цены в `/v1/models` (формат OpenRouter), они подхватятся автоматически
- **Ваши** — щёлкните по любой цене и впишите свою (прокси-реселлеры считают по-своему): сохраняется локально, кнопка «сброс» возвращает значение по умолчанию

Стоимость считается везде: под каждым ответом — фактический расход токенов с сервера (поле `usage`) и цена; у поля ввода — оценка промпта; в подписи чата — накопленная сумма. Если сервер не отдаёт `usage`, включается оценка ~3.6 симв/ток (помечается `~`).

## Пресеты инструкций

| Пресет | Для чего |
|---|---|
| **НейроАгент** | Прямой, самостоятельный ассистент «сделай, а не объясни». Даёт готовый результат, не выпендривается. По умолчанию |
| **Кодер** | Только код и команды, минимум прозы |
| **Аналитик** | Структура, таблицы, числа, выводы |
| **Обычный чат** | Лёгкая беседа без формальностей |

Пресет — это просто текст в поле «Системные инструкции». Правьте как угодно: сделайте своего «жёсткого кодера» или «дружелюбного кота» — модель примет любой характер.

## Поддерживаемые API

Любой сервис формата `/v1/chat/completions`:

- прокси-реселлеры Claude (как `api.gym-rat.online`)
- [OpenRouter](https://openrouter.ai) (сотни моделей одним ключом)
- [OpenAI](https://api.openai.com/v1)
- локальная [ollama](http://localhost:11434/v1) — бесплатно, на своей машине
- self-hosted [LiteLLM](https://github.com/BerriAI/litellm) / [vLLM](https://github.com/vllm-project/vllm)

## Если «Проверка не удалась: Failed to fetch» (CORS)

Симптом: кнопка «Проверить» в веб-версии падает с `Failed to fetch`, хотя ключ рабочий (например, тот же ключ работает в Claude Code или в curl).

Причина: браузер перед запросом с заголовком `Authorization` отправляет **preflight-запрос OPTIONS** и требует в ответе заголовок `Access-Control-Allow-Origin`. Часть прокси-сервисов (включая `api.gym-rat.online` на момент ноября 2026 — проверено: OPTIONS отвечает 204 с `Access-Control-Allow-Methods`/`Allow-Headers`, но **без** `Access-Control-Allow-Origin`) — браузер считает preflight проваленным и блокирует запрос целиком, ещё до его отправки. Сервер и ключ при этом полностью исправны: это ограничение безопасности браузера, а не неработающий API.

Два решения:

1. **Десктопная версия (без настройки сервера).** `NeuroShell.exe` открывает этот же интерфейс в отдельном окне через локальный прокси (`127.0.0.1:8947`) — запросы к API идут из обычного процесса, а не из браузерной страницы, поэтому CORS не применяется. Скачайте exe в [Releases](https://github.com/Genocide12/neuro-shell/releases), вставьте тот же ключ и работайте.

2. **Починить CORS на сервере** (если он ваш). В nginx нужно, чтобы preflight получал правильные заголовки. В блок `server` (или `location`, где проксируется API) добавьте:

   ```nginx
   location / {
       if ($request_method = OPTIONS) {
           add_header Access-Control-Allow-Origin $http_origin always;
           add_header Access-Control-Allow-Methods "GET, POST, PUT, PATCH, DELETE, OPTIONS" always;
           add_header Access-Control-Allow-Headers "Authorization, Content-Type, X-Requested-With, x-api-key, X-API-Key, anthropic-version, anthropic-beta, accept, origin" always;
           add_header Access-Control-Max-Age 86400 always;
           return 204;
       }
       # … остальной конфиг проксирования …
   }
   ```

   Затем `nginx -t && systemctl reload nginx`. После этого веб-версия заработает без изменений.

> С версии 1.0.1 NeuroShell сам распознаёт эту ситуацию: «Проверить» сообщит, что ключ и сервер в порядке, а блокирует именно CORS, и покажет оба решения прямо в настройках.

## Как это устроено

```
┌─────────────────────────────────────────────┐
│  index.html (всё приложение, ~78 КБ)        │
│  ┌───────────┐  ┌──────────────────────┐    │
│  │  UI (CSS) │  │  Логика (JS)         │    │
│  │  чат/тема │  │  стриминг, история,  │    │
│  │           │  │  markdown, артефакты │    │
│  └───────────┘  └──────────┬───────────┘    │
└─────────────────────────────┼───────────────┘
                              │ fetch (ключ из localStorage)
                              ▼
                    ваш API (OpenAI-совместимый)

Десктоп-версия: то же самое, но fetch перехватывает мост
NeuroShellBridge и ведёт запросы через локальный прокси
(127.0.0.1) — поэтому CORS не важен.
```

## Сборка из исходников

```bash
# веб-версия: пересобрать index.html из src/
# (пишет и корневой index.html для GitHub Pages, и internal/site/index.html для exe)
python3 scripts/build_site.py

# десктоп-версия: собрать exe (нужен Go 1.22+)
GOOS=windows GOARCH=amd64 CGO_ENABLED=0 go build -trimpath \
  -ldflags "-s -w -H=windowsgui" -o NeuroShell.exe ./cmd/neuroshell

# мок-API для локальных тестов интерфейса (без ключа и расхода токенов)
python3 scripts/mock_api.py 8788   # затем укажите в настройках http://127.0.0.1:8788/v1
```

`-H=windowsgui` прячет консольное окно — остаётся только окно приложения. Без этого флага exe запустится с чёрной консолью (удобно для отладки).

Структура проекта:

```
neuro-shell/
├── index.html              # собранный одностраничник (веб-версия целиком)
├── src/
│   ├── body.html           # разметка
│   ├── style.css           # стили
│   ├── app.js              # логика приложения (+ цены на токены)
│   └── bridge.js           # мост для десктоп-версии
├── scripts/
│   ├── build_site.py       # сборка index.html из src/
│   └── mock_api.py         # мок OpenAI-совместимого API для тестов
├── cmd/neuroshell/         # Go-обёртка: сервер + прокси + своё окно
└── internal/site/          # встраивание index.html в exe (go:embed)
```

Пуш тега `v*` в GitHub автоматически собирает exe и публикует релиз (workflow `.github/workflows/build.yml`).

## Приватность

- API-ключ, чаты, настройки и ваши цены хранятся в **localStorage** вашего браузера (веб) — на вашей машине
- Запросы уходят **напрямую** в указанный вами API
- В коде нет аналитики, счётчиков и внешних загрузок
- Единственный, кто видит ваш трафик, — оператор выбранного вами API-сервиса
