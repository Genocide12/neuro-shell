Браузер блокирует запросы к этому API (CORS)

Сервер не отвечает на preflight-запрос OPTIONS заголовком Access-Control-Allow-Origin, поэтому браузер не пускает запросы с вашим ключом. Сам ключ и сервер при этом могут быть полностью рабочими.

Быстрое решение: скачайте настольную версию NeuroShell.exe — она открывает этот же интерфейс, но ходит в API напрямую через локальный прокси, без ограничений CORS. Ссылка — в README репозитория (Releases).

Если вы управляете сервером: добавьте в nginx (в блок server или location прокси) ответ на preflight:

location / {
    if ($request_method = OPTIONS) {
        add_header Access-Control-Allow-Origin $http_origin always;
        add_header Access-Control-Allow-Methods "GET, POST, OPTIONS" always;
        add_header Access-Control-Allow-Headers "Authorization, Content-Type, anthropic-version, x-api-key" always;
        add_header Access-Control-Max-Age 86400 always;
        return 204;
    }
    # … остальной конфиг проксирования …
}

После правки nginx: nginx -t && systemctl reload nginx. Подробнее — README, раздел «CORS».
