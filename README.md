# NeuroShell

**Лёгкая оболочка чата для OpenAI-совместимых API.** Один HTML-интерфейс, потоковая генерация, история чатов, вложения, предпросмотр HTML-артефактов, локальные файловые инструменты в настольной версии и интеграция с GitHub.

![версия](https://img.shields.io/badge/версия-1.4.1-6c8cff) ![тип](https://img.shields.io/badge/тип-HTML%20%2B%20Go-green)

## Возможности

- Чат со стримингом, история и локальные настройки.
- Поддержка OpenAI-совместимых API: OpenRouter, OpenAI, прокси и Ollama.
- Десктопная версия с локальным прокси, обходящим браузерные CORS-ограничения.
- Голосовой ввод в поддерживаемых браузерах; микрофон остаётся включённым, пока пользователь не остановит его. Распознавание может зависеть от движка браузера.
- Автопрокрутка, пока чат закреплён у низа; кнопка возврата к последним сообщениям при прокрутке вверх.
- Очередь текстовых сообщений, отправленных во время генерации.
- Локальный журнал сетевых и JavaScript-ошибок без сохранения ключей, заголовков, содержимого запросов или текста чата.
- Подключение локальных инструментов для файлов и GitHub в режиме агента.

## Запуск сайта

Откройте [GitHub Pages](https://genocide12.github.io/neuro-shell/), укажите Base URL, модель и API-ключ в настройках.

## Десктопная версия

Скачайте последний успешный `NeuroShell.exe` со страницы [Releases](https://github.com/Genocide12/neuro-shell/releases). Обычные коммиты исходников не обновляют уже скачанный EXE: нужен релизный workflow, собираемый тегом `v*`.

## Сборка и проверки

```bash
python3 scripts/build_site.py
for file in src/*.js; do node --check "$file"; done
go test ./...
GOOS=windows GOARCH=amd64 CGO_ENABLED=0 go build -trimpath -ldflags "-s -w -H=windowsgui" -o NeuroShell.exe ./cmd/neuroshell
```

GitHub Actions запускает сборку и проверки на push/PR. Сборка релиза запускается тегом вида `v1.4.1` после успешной CI-проверки.

## Диагностика сетевых ошибок

- `401` — сервер отклонил авторизацию; проверьте ключ и формат авторизации.
- `404` — проверьте маршрут API и идентификатор модели.
- `502` с `TLS handshake timeout` — upstream не завершил TLS-соединение вовремя; это транспортная ошибка между прокси и API, а не доказательство неверного ключа. Повтор POST автоматически не выполняется, чтобы не допустить двойного списания.
- Ошибки записываются локально в ограниченный журнал; секреты и содержимое чата не сохраняются.

## Безопасность

API-ключ хранится локально в браузерном профиле. Не публикуйте экспорт настроек: он может содержать секреты. Не вставляйте ключ в отчёты об ошибках.
